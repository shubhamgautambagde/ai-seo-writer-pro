AI SEO Writer Pro

Advanced AI-powered WordPress SEO article generator plugin — v1.0.0

Generate high-quality, SEO-optimized articles directly from your WordPress admin dashboard, with OpenAI, Google Gemini, Anthropic Claude, OpenRouter or a custom API.

Features

  • AI article generator — topic, keywords, audience, intent, tone, length, content type
  • SEO title, meta description, slug, headings, FAQ, schema markup, TOC
  • Bulk generator via CSV + WP-Cron queue, save as draft / publish / schedule
  • SEO score analyzer (0–100), readability, keyword density, link & image checks
  • 16 content templates, AI image generation, Gutenberg-compatible output

Requirements

WordPress 6.0+, PHP 8.1+, MySQL 5.7+ / MariaDB 10.3+, and an API key from at least one supported AI provider.

Install

  1. Download the ZIP below.
  2. WordPress Admin → Plugins → Add New → Upload Plugin → Install & Activate.
  3. AI SEO Writer Pro → API Settings me apni API key daalo → Test Connection.
  4. AI Article Generator se pehla article banao.
